# inceptools agent instructions

This repository is an inceptools Go framework and CLI. Before changing code,
read `AGENTS.md` and the canonical framework skill at
`.agents/skills/inceptools/SKILL.md`. Do not duplicate their instructions here.

Use the existing `icpt` generator and framework packages, preserve the module
layering rules, put tests in the mirrored `tests/` tree, and run the relevant
root and `examples/` module checks before handoff. Ask before destructive
release, tag, migration, or external publishing operations.
